# 💳 Бот-трекер подписок и пробных периодов (SubTrack Bot)

Telegram-бот на базе **Python 3** и **aiogram 3.x** для учета регулярных платежей, отслеживания бесплатных пробных периодов (триалов) и автоматических напоминаний о списаниях.

---

## 🌟 Основные возможности

1. **⏳ Трекинг пробных периодов (Триалов):**
   - Удобное добавление с кнопками быстрого выбора срока (3, 7, 14, 30, 60 дней или ручной ввод даты).
   - Автоматические предупреждения: **за 3 дня, за 1 день и в день списания**.
   - Кнопки прямо в сообщении-напоминалке: *«✅ Я отменил»*, *«👍 Продлил»*, *«🔄 Сделать постоянной»*.

2. **💳 Учет постоянных подписок:**
   - Пресеты популярных сервисов (Яндекс Плюс, Telegram Premium, Spotify, YouTube, VPN и др.) или ввод любого своего названия.
   - Ежемесячные и годовые подписки.
   - Напоминания перед регулярными списаниями.

3. **📊 Финансовая аналитика:**
   - Подсчет общих расходов в месяц и год.
   - Отображение ближайшего запланированного списания.

4. **⚡ Быстрое управление:**
   - Просмотр всех сервисов списком.
   - Удаление, перенос дат и перевод триалов в постоянные подписки в 1 клик.

## 🚀 Быстрый запуск

### 1. Получите токен бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название и юзернейм для бота (например, `MySubTrackerBot`).
4. Скопируйте полученный токен (вида `123456789:ABCdefGHIjkl...`).

### 2. Укажите токен
Откройте файл `.env` в папке `Documents/bot2/` и вставьте ваш токен:
```ini
BOT_TOKEN=123456789:ABCdefGHIjkl...
```

### 3. Запустите бота
Откройте Терминал и выполните:
```bash
cd ~/Documents/bot2
./venv/bin/python main.py
```

После этого откройте вашего бота в Telegram и отправьте команду `/start`!
